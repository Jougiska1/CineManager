## Objetivo do software

O CineManager é um sistema desktop para gestão de locadoras de filmes, com o objetivo de modernizar e simplificar o controle do acervo, dos clientes e das locações, substituindo processos manuais por uma plataforma digital integrada.

## Funcionalidades do sistema

- Login de usuário
- Menu principal de navegação
- Cadastro de clientes
- Listagem de clientes
- Cadastro de filmes
- Listagem de filmes
- Registro de locações
- Consulta de vendas/locações
- Controle de estoque de filmes
